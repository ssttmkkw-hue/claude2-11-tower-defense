# 奥术壁垒 · Arcane Bastion

一款基于 **three.js + Vite** 的 3D 塔防游戏：建造防御塔、**召唤并亲自操控英雄**、**构筑魔法卡组**并在战斗中施放华丽法术。

**支持桌面与手机浏览器**（竖屏 / 横屏均可，约 360–430px 宽的手机即可完整游玩）。纯静态页面，可直接部署到 GitHub Pages。

## 快速上手

1. 主菜单 →「开始征程」→ 选择地图（新手推荐 *翠语山谷*），再选一件初始遗物。
2. 在道路两侧建造防御塔，召唤 1–3 名英雄（花费金币）。
3. 点击「开始第 N 波」。战斗中法力自动恢复，打出卡牌、释放英雄技能。
4. 每波结束三选一卡牌奖励（或精简卡组），每击败首领三选一遗物。守住所有波次即胜利。

## 特色

- **6 种防御塔**（箭塔、炮台、奥术法师塔、寒霜方尖碑、雷霆尖塔、法力之泉），每种 3 级，模型随等级变化
- **4 名英雄**：圣光骑士、炎之术士、林地游侠、冰霜女巫，各有 1 个被动 + 3 个技能（Q/E/R）
  - 按住技能键瞄准（显示施法距离与范围），松开施放；也可点击技能按钮后点击地面
  - 点击敌人**集火**，H 键**坚守原地**，WASD 直接操控
  - 升级获得**技能点**（Shift+Q/E/R 学习），每级 +30% 威力、-8% 冷却；终极技能在 3 级领悟
- **43 张魔法卡牌**，分为普通 / 稀有 / 史诗 / **传说** 四种稀有度（天启、神威降临、万雷天牢、超新星……）
- **流派羁绊**：卡牌分属烈焰、寒霜、风暴、奥术、自然、圣光六个流派，卡组中同流派达到 3 / 6 张激活全局加成
- **连携**：连续打出同流派卡牌，每层伤害 +15%
- **遗物**：18 种单局遗物，开局与每次击败首领后三选一
- **卡组构筑**：出征前组建 10–20 张卡组（可按稀有度 / 流派筛选，实时显示羁绊）；每波胜利后三选一奖励（偏向主流派）或**精简卡组**，史诗/传说卡只能通过奖励解锁（本地存档）
- **波次预览**：建造阶段显示下一波敌人构成；波次为手工设计的模板，难度曲线平滑
- **13 种敌人 + 4 个首领**：史莱姆（会分裂）、疾风狼、铁甲骑士、蝙蝠（飞行）、萨满（治疗）、幽魂（相位免疫物理）、沼泽巨魔（再生，灼烧可抑制）、自爆地精（被阻挡或死亡时爆炸眩晕英雄）、圣盾卫士（周围敌人减伤 30%）……
- **首领机制**：岩石巨像（践踏眩晕）、暗影巫妖（召唤骷髅）、炽炎古龙（飞行 + 喷火）、**虚空领主**（沿路径闪烁跃迁，66% / 33% 生命展开虚空屏障并召唤仆从）；所有首领半血**狂暴**，登场时镜头特写并提示机制
- **4 张地图**：翠语山谷、熔火裂谷（双路线）、霜寒冰原、**暮影沼泽**（双路线汇流，20 波）
- **完美防守**：一波无漏怪获得额外金币；圣坛濒危时心跳警告
- **视觉特效**：GPU 粒子、Bloom 辉光、程序化魔法印记（六芒星 + 旋转符文）、符文法阵、体积火球核心、双层辉光闪电、漩涡粒子、光柱、冲击波、屏幕震动、命中闪白、动态光源、焦痕贴花
- **音效**：全部由 Web Audio 实时合成，含生成式背景音乐

## 操作

### 手机 / 触屏

| 操作 | 手势 |
| --- | --- |
| 选择英雄 / 防御塔，移动英雄，集火敌人 | 单指点击 |
| 平移镜头 | 单指拖动空白处 |
| 缩放镜头 | 双指捏合 |
| 出牌 | **把卡牌拖到战场松手**；或点卡牌后点地面 |
| 英雄技能 | **把技能按钮拖到目标处松手**；或点按钮后点地面；自身范围技能点击即放 |
| 建造 | 点右侧塔图标，再点空地（可按住拖动预览位置） |
| 取消瞄准 / 建造 | 顶部提示条上的「✖ 取消」 |
| 查看详情 | 长按卡牌、技能、塔按钮、英雄头像；点击遗物 / 流派 / 波次预览 |
| 学习技能 / 坚守 | 技能按钮上的「+」 / 技能栏的 🛡 按钮 |

竖屏时镜头自动旋转 90°，让地图长边沿屏幕竖向展开（敌人自上而下进攻）。切到后台会自动暂停。

### 桌面

| 操作 | 按键 |
| --- | --- |
| 选择 / 移动英雄 | 左键点击英雄 / 地面；右键移动 |
| 直接操控英雄 | WASD |
| 英雄技能 | 按住 Q / E / R 瞄准，松开施放 |
| 学习技能 | Shift + Q / E / R |
| 集火 / 坚守 | 点击敌人 / H |
| 出牌 | 点击卡牌或数字键 1–9，再点击目标；右键取消 |
| 切换英雄 / 镜头聚焦 | Tab / F |
| 建造 | 点击右侧防御塔，再点击空地（Shift 连续建造） |
| 升级 / 出售所选塔 | U / X |
| 开始下一波 | 空格 |
| 镜头 | 方向键平移，滚轮缩放 |
| 暂停 | Esc |

卡牌和技能按钮在桌面上同样可以直接拖到战场施放。

## 性能

- 手机自动使用低画质档：像素比上限 1.5、关闭 MSAA、阴影贴图 1024、四分之一分辨率辉光、粒子与动态光源减半
- 帧率持续低于 38 FPS 时自动逐级降低渲染分辨率
- 调试参数：`?mobile` 强制手机画质与布局判定，`?touch` 强制触屏模式

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览构建结果
```

`vite.config.js` 使用相对路径 `base: './'`，构建产物可直接部署到 GitHub Pages 子路径（如 `/claude2-11-tower-defense/`）。

素材说明见 [ASSETS.md](./ASSETS.md)。
