# 奥术壁垒 · Arcane Bastion

一款基于 **three.js + Vite** 的 3D 塔防游戏：建造防御塔、**召唤并亲自操控英雄**、**构筑魔法卡组**并在战斗中施放华丽法术。

## 特色

- **6 种防御塔**（箭塔、炮台、奥术法师塔、寒霜方尖碑、雷霆尖塔、法力之泉），每种 3 级，模型随等级变化
- **4 名英雄**：圣光骑士、炎之术士、林地游侠、冰霜女巫，各有 1 个被动 + 3 个技能（Q/E/R）
  - 按住技能键瞄准（显示施法距离与范围），松开施放；也可点击技能按钮后点击地面
  - 点击敌人**集火**，H 键**坚守原地**，WASD 直接操控
  - 升级获得**技能点**（Shift+Q/E/R 学习），每级 +30% 威力、-8% 冷却；终极技能在 3 级领悟
- **38 张魔法卡牌**，分为普通 / 稀有 / 史诗 / **传说** 四种稀有度（天启、神威降临、万雷天牢……）
- **流派羁绊**：卡牌分属烈焰、寒霜、风暴、奥术、自然、圣光六个流派，卡组中同流派达到 3 / 6 张激活全局加成
- **连携**：连续打出同流派卡牌，每层伤害 +15%
- **遗物**：18 种单局遗物，开局与每次击败首领后三选一
- **卡组构筑**：出征前组建 10–20 张卡组（可按稀有度 / 流派筛选，实时显示羁绊）；每波胜利后三选一奖励（偏向主流派）或**精简卡组**，史诗/传说卡只能通过奖励解锁（本地存档）
- **波次预览**：建造阶段显示下一波敌人构成；波次为手工设计的模板，难度曲线平滑
- **9 种敌人 + 3 个首领**：史莱姆（会分裂）、疾风狼、铁甲骑士、蝙蝠（飞行）、萨满（治疗）、幽魂（相位免疫物理）、岩石巨像（践踏眩晕英雄）、暗影巫妖（召唤骷髅）、炽炎古龙（飞行 + 喷火）
- **3 张地图**：翠语山谷、熔火裂谷（双路线）、霜寒冰原
- **视觉特效**：GPU 粒子、Bloom 辉光、程序化魔法印记（六芒星 + 旋转符文）、符文法阵、体积火球核心、双层辉光闪电、漩涡粒子、光柱、冲击波、屏幕震动、命中闪白、动态光源、焦痕贴花
- **音效**：全部由 Web Audio 实时合成，含生成式背景音乐

## 操作

| 操作 | 按键 |
| --- | --- |
| 选择 / 移动英雄 | 左键点击英雄 / 地面；右键移动 |
| 直接操控英雄 | WASD |
| 英雄技能 | 按住 Q / E / R 瞄准，松开施放 |
| 学习技能 | Shift + Q / E / R |
| 集火 / 坚守 | 点击敌人 / H |
| 出牌 | 点击卡牌或数字键 1–9，再点击目标；右键取消 |
| 切换英雄 / 镜头聚焦 | Tab / F |
| 建造 | 点击右侧防御塔，再点击空地（Shift 连续建造） |
| 升级 / 出售所选塔 | U / X |
| 开始下一波 | 空格 |
| 镜头 | 方向键平移，滚轮缩放 |
| 暂停 | Esc |

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览构建结果
```

`vite.config.js` 使用相对路径 `base: './'`，构建产物可直接部署到 GitHub Pages 子路径（如 `/claude2-11-tower-defense/`）。

素材说明见 [ASSETS.md](./ASSETS.md)。
