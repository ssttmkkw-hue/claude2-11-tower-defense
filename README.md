# 奥术壁垒 · Arcane Bastion

一款基于 **three.js + Vite** 的 3D 塔防游戏：建造防御塔、**召唤并亲自操控英雄**、**构筑魔法卡组**并在战斗中施放华丽法术。

## 特色

- **6 种防御塔**（箭塔、炮台、奥术法师塔、寒霜方尖碑、雷霆尖塔、法力之泉），每种 3 级，模型随等级变化
- **4 名英雄**：圣光骑士、炎之术士、林地游侠、冰霜女巫，各有 3 个技能（Q/E/R）。点击移动或 WASD 直接操控，会升级、会阵亡复活；近战英雄可阻挡敌人
- **26 张魔法卡牌**：火球、冰霜新星、连锁闪电、陨石、虚空黑洞、时间停滞、星辰射线、凤凰召唤……
- **卡组构筑**：出征前组建 10–20 张卡组；每波胜利后三选一奖励，史诗卡只能通过奖励解锁（本地存档）
- **9 种敌人 + 3 个首领**：史莱姆（会分裂）、疾风狼、铁甲骑士、蝙蝠（飞行）、萨满（治疗）、幽魂（相位免疫物理）、岩石巨像（践踏眩晕英雄）、暗影巫妖（召唤骷髅）、炽炎古龙（飞行 + 喷火）
- **3 张地图**：翠语山谷、熔火裂谷（双路线）、霜寒冰原
- **视觉特效**：GPU 粒子、Bloom 辉光、冲击波着色器、光柱、闪电、拖尾、屏幕震动、命中闪白、动态光源、焦痕贴花
- **音效**：全部由 Web Audio 实时合成，含生成式背景音乐

## 操作

| 操作 | 按键 |
| --- | --- |
| 选择 / 移动英雄 | 左键点击英雄 / 地面；右键移动 |
| 直接操控英雄 | WASD |
| 英雄技能 | Q / E / R（朝鼠标位置） |
| 出牌 | 点击卡牌或数字键 1–7，再点击目标；右键取消 |
| 切换英雄 / 镜头聚焦 | Tab / F |
| 建造 | 点击右侧防御塔，再点击空地（Shift 连续建造） |
| 升级 / 出售所选塔 | U / X |
| 开始下一波 | 空格 |
| 镜头 | 方向键平移，滚轮缩放 |
| 暂停 | Esc |

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览构建结果
```

`vite.config.js` 使用相对路径 `base: './'`，构建产物可直接部署到 GitHub Pages 子路径（如 `/claude2-11-tower-defense/`）。

素材说明见 [ASSETS.md](./ASSETS.md)。
